# 02 · 数据契约

> 所有契约在 `packages/contracts` 中以 Zod schema 定义，TypeScript 类型由 schema 推出（`z.infer`），不手写重复的接口。本文用 TypeScript 语法表示字段，便于阅读。
> 原则：先定契约再写算法。下游模块只能通过这些契约读取上游结果。

## 1. 版本策略

1. **每个契约都有 `schema` 字段**，值为 `<名称>/<主版本>`，例如 `'engine-delivery/1'`。主版本内只允许**新增可选字段**；删除字段、改变字段含义、改变枚举取值都要升主版本。
2. **算法版本是一个复合对象**，写入每次分析的输出和数据库：

```ts
interface AlgorithmVersion {
  pipeline: string;                       // 'pipeline/1.0.0'
  contracts: string;                      // contracts 包的 semver
  astroTime: string;                      // 'astro-time/1.0.0'
  engines: Record<EngineId, string>;      // { bazi: 'bazi/1.0.0', ... }
  ruleRegistry: string;                   // 规则登记表版本（内容哈希前 12 位 + semver）
  choiceCatalog: string;                  // 选择目录、ChoiceTypeMap、JointEventRules 的版本
  parameters: string;                     // λ、b₀、ι、κ、K 等参数集的版本，如 'params/2026.1'
  eraData: string;                        // 'era-data/2026.1'
  detmath: string;                        // 确定性数学库版本
}
```

3. **任何影响输出字节的改动都要升对应分量的版本**。CI 中有一组「版本闸门」测试：固定输入的输出哈希一旦变化而版本号没变，测试失败。
4. **规范化序列化**：所有输出用 `canonicalJson`（键按 Unicode 码点排序、无多余空白、数值用 `detmath` 的规范十进制格式：有限数保留 12 位有效数字、去掉末尾的零，`-0` 写成 `0`，禁止 NaN 和 Infinity）。所有哈希都对规范化后的字节计算 SHA-256。
5. **旧数据兼容**：旧表 `prediction_runs` 的数据不迁移到新契约（结构不可比），只读保留（08 文档 §5）。

## 2. 基础类型

```ts
type Iso8601Utc = string;          // '2016-02-04T08:46:00Z'，只用于绝对瞬时
type CivilDate = string;           // '2016-02-04'，当地日期
type YearSlot = `Y${number}` | `Y${number}M${number}`;   // 时间槽，与时间精度 r 对应
type PersonId = string;            // 'P-' + 16 位十六进制，由用户账户内单调生成，不含个人信息
type Digest = string;              // SHA-256 十六进制

type EngineId = 'bazi' | 'ziwei' | 'tieban' | 'western' | 'vedic' | 'numerology' | 'mayan' | 'kabbalah'
              | 'liuyao' | 'meihua' | 'qimen' | 'liuren' | 'taiyi';
type EngineClass = 'natal' | 'divinatory';
type EngineFamily = 'chinese_calendar' | 'astronomical' | 'name_number' | 'mesoamerican';
type ImplStatus = 'complete' | 'partial' | 'needs_source_validation' | 'experimental';
type Verification = 'verified' | 'cited_unverified' | 'unverified' | 'project_assumption';

type Domain = 'career' | 'wealth' | 'relationship' | 'health' | 'family' | 'study' | 'migration' | 'turning';
type RelationRole = 'self' | 'father' | 'mother' | 'sibling' | 'spouse' | 'child'
  | 'mentor' | 'superior' | 'subordinate' | 'business_partner' | 'friend' | 'rival';
type Polarity = 'favorable' | 'unfavorable' | 'mixed' | 'neutral';

type Provenance =
  | { kind: 'engine_rule'; engineId: EngineId; ruleId: string; signalId: string }
  | { kind: 'user_fact'; realityItemId: string }
  | { kind: 'historical_record'; recordId: string; datasetVersion: string }
  | { kind: 'enumerated'; address: WorldAddress };
```

## 3. 输入

```ts
interface BirthInput {
  schema: 'birth-input/1';
  localDate: CivilDate;                 // 当地民用日期
  localTime: string | null;             // 'HH:MM'，未知为 null（时柱等规则进入 omissions）
  timeAccuracy: 'exact' | 'within_15min' | 'within_1h' | 'unknown';
  timezone: string;                     // IANA 时区名，必填；不接受固定偏移
  disambiguation: 'earlier' | 'later' | null; // 夏令时重叠时段必须显式选择，否则拒绝
  place: { latitude: number; longitude: number; regionCode: string; label: string | null };
  sex: 'male' | 'female' | null;        // 只用于需要它的引擎；缺失时相关规则进入 omissions
  calculationName: { script: 'latin' | 'hebrew' | 'other'; value: string } | null; // 仅数字命理、卡巴拉使用，只取用户显式提供的拼写
}

interface Person {
  schema: 'person/1';
  personId: PersonId;
  kind: 'self' | 'complete' | 'derived';   // derived = 无出生信息，由本人 relationSlots 推出
  label: string;                           // 默认是关系称谓，如「父亲」；不要求真实姓名
  birth: BirthInput | null;                // complete / self 必填；derived 为 null
  relationsToSelf: { role: RelationRole; from: CivilDate | null; to: CivilDate | null }[];
  inputDigest: Digest | null;              // birth 的规范化哈希
}

interface AnalysisRequest {
  schema: 'analysis-request/1';
  self: Person;
  others: Person[];                        // 上限见 10 文档 D3
  reality: RealityContext | null;          // 为 null 时只做到第 5 段
  bounds: MaterializationBounds;
  parameters: string;                      // 参数集版本
}
```

## 4. 规则登记与引擎交付

```ts
interface RuleRecord {
  schema: 'rule/1';
  ruleId: string;                          // '<engineId>.<area>.<name>'，全小写连字符，一旦发布不得改名
  engineId: EngineId;
  school: string;
  statement: string;                       // 规则内容的转述（不抄录受版权保护的原文）
  source: {
    kind: 'classic' | 'technical' | 'project';
    work: string | null;                   // 典籍名或技术文献名
    edition: string | null;                // 版本；不知道就是 null
    locator: string | null;                // 卷章/页码/节号；不知道就是 null（不得编造）
    url: string | null;
  };
  verification: Verification;
  produces: ('chart' | 'period' | 'tendency' | 'key_node' | 'relation_slot')[];
  addedIn: string;                         // 规则登记表版本
  notes: string | null;
}
```

**校验规则**（CI 强制）：`verification = 'verified'` 时 `work`、`edition`、`locator` 都必须非空，且必须有至少一个独立黄金用例引用该 ruleId；`cited_unverified` 时 `work` 非空；`unverified` 时允许全空。

`EngineDelivery` 的字段定义见 `03-引擎设计` 各文档开头共用的说明，这里给出最终版本：

```ts
interface EngineDelivery {
  schema: 'engine-delivery/1';
  engineId: EngineId;
  engineVersion: string;
  engineClass: EngineClass;
  family: EngineFamily;
  school: string;
  status: ImplStatus;
  subjectPersonId: PersonId;
  inputDigest: Digest;                     // 引擎实际读取的输入字段的规范化哈希
  chart: { kind: string; data: unknown };  // 每个引擎自定的版本化盘面类型，如 'bazi.chart/1'，各自有 schema
  timeline: NativePeriod[];
  signals: Signal[];
  relationSlots: RelationSlot[];
  omissions: Omission[];
  rulesUsed: string[];                     // 排序、去重
}

interface NativePeriod {
  periodId: string;                        // 'bazi.liunian.2016'
  unit: string;                            // 'bazi.dayun' | 'bazi.liunian' | 'ziwei.daxian' | ...
  label: string;
  start: Iso8601Utc; end: Iso8601Utc;      // 绝对时间，end 为开区间
  parentPeriodId: string | null;
  ruleId: string;
}

interface Signal {
  signalId: string;                        // `${engineId}:${ruleId}:${periodId}:${domain}:${subjectRole}`
  ruleId: string;
  periodId: string;
  domain: Domain;
  subjectRole: RelationRole;
  kind: 'tendency' | 'key_node';
  polarity: Polarity;
  intensity: 1 | 2 | 3 | null;
  evidence: string[];                      // chart 内路径
}

interface RelationSlot {
  role: RelationRole;
  ruleId: string;
  indicators: string[];
  attributes: { key: string; value: string; ruleId: string }[];
}

interface Omission {
  what: string;
  reason: 'no_rule' | 'not_implemented' | 'input_missing' | 'out_of_scope' | 'ambiguous_input';
  detail: string;
}
```

**不存在的东西**：`EngineDelivery` 中没有 0–100 分数、没有单一「置信度」、没有事件概率、没有任何死亡或寿命字段。`Domain` 枚举里也没有这类取值。

**预留的扩展**（不在第一版）：太乙等以国运为对象的体系，其输出不属于某个人，需要一种 `EraSignal`（对象是「地区 × 时段」而非人物）。第一版不定义它，太乙不进入世界生成（见 `03-引擎设计/taiyi.md`）。

## 5. 一级世界

```ts
interface PrimaryWorld {
  schema: 'primary-world/1';
  worldId: string;                         // `${personId}:${engineId}`
  personId: PersonId;
  engineId: EngineId;
  deliveryDigest: Digest;
  periods: NativePeriod[];                 // 原样保留引擎时间结构
  tendencies: Signal[];                    // kind = tendency
  branchPoints: BranchPoint[];             // 分岔点，惰性世界的「坐标轴」
  derivedPersons: DerivedPersonView[];     // 该引擎眼中的他人（来自 relationSlots）
  eraBackground: string[];                 // 关联的 EraRecord.recordId（出生地 × 生存年代）
  worldCount: { log2: number };            // = branchPoints.length
}

interface BranchPoint {
  branchPointId: string;                   // `${engineId}:${ruleId}:${periodId}:${subjectRole}`
  ruleId: string;
  periodId: string;
  subjectRole: RelationRole;
  domains: Domain[];
  polarity: Polarity;                      // 「应验」支的极性
  intensity: 1 | 2 | 3 | null;
  window: { start: Iso8601Utc; end: Iso8601Utc };
  signalIds: string[];
  verification: Verification;              // 涉及规则中最弱的一环
}

interface DerivedPersonView {
  role: RelationRole;
  slot: RelationSlot;
  signals: string[];                       // 当事人为该角色的 signalId
}
```

一套具体的一级世界由 `PrimaryWorldInstance = { worldId, realized: bitstring }` 表示，第 i 位对应 `branchPoints[i]` 是否应验。只在界面浏览时按需生成。

## 6. 权重提取

```ts
interface ChoiceCandidate {
  candidateId: string;                     // `${personId}:${engineId}:${choiceType}:${branchPointId}`
  personId: PersonId;
  engineId: EngineId;
  choiceType: ChoiceType;
  branchPointId: string;
  window: { start: Iso8601Utc; end: Iso8601Utc };
  polarity: Polarity;
  factors: { irrev: number; scope: number; intens: number; statusFactor: number; verifFactor: number };
  weight: number;                          // = 各因子之积
  flags: ('intensity_unknown')[];
}

type ChoiceType = 'partnership' | 'children' | 'residence' | 'career' | 'family_care' | 'education' | 'major_finance';

interface MajorChoice {
  schema: 'major-choice/1';
  choiceId: string;                        // 稳定键：`${choiceType}@${窗口起始年}:${排序后的人物集合}`
  choiceType: ChoiceType;
  window: { start: Iso8601Utc; end: Iso8601Utc };
  persons: PersonId[];                     // 排序
  sources: {                               // 回溯
    candidateId: string; personId: PersonId; engineId: EngineId; ruleId: string; branchPointId: string; weight: number;
  }[];
  perPersonWeight: Record<PersonId, number>;   // 同人跨引擎合并后
  perEngineSupport: Record<EngineId, number>;  // 用于二级世界中的 P(arise)
  weight: number;                          // 跨人物合并后的总权重
  rank: number;
  flags: ('unilateral' | 'polarity_conflict' | 'window_disagreement' | 'intensity_unknown' | 'activated_by_fact' | 'reality_only')[];
  materialized: boolean;                   // 是否进入前 K
}

interface ExtractionResult {
  schema: 'extraction/1';
  materialized: MajorChoice[];             // 按 rank
  pool: MajorChoice[];                     // 未物化的候选池
  catalogVersion: string;
}
```

## 7. 二级世界

```ts
type WorldAddress = string;                // 'v1/<rootDigest>/<choiceId>=<outcomeId>@<YearSlot>/...'

interface MaterializationBounds {
  maxChoices: number;                      // K
  timeResolution: 'year' | 'month';        // r
  horizonYear: number;                     // H（推演边界，不是寿命估计）
  candidatePoolSize: number;
}

interface WorldState {
  year: number;
  persons: Record<PersonId, PersonState>;
}

interface PersonState {
  educationStage: 'none' | 'primary' | 'secondary' | 'tertiary' | 'postgraduate';
  inEducation: boolean;
  workStatus: 'not_working' | 'employed' | 'self_employed' | 'between_jobs' | 'retired';
  careerLevel: 0 | 1 | 2 | 3;
  wealthBand: 0 | 1 | 2 | 3 | 4 | null;
  partnership: 'single' | 'partnered' | 'married' | 'separated';
  partnerId: PersonId | null;
  childrenCount: number;
  caregiving: 'none' | 'for_parent' | 'for_child' | 'both';
  residence: { regionCode: string; city: string | null };
  healthAttention: 'none' | 'attention';
  provenance: Record<string, Provenance>;  // 每个变量的来源
}

interface StageGame {                      // 第 k 个阶段在某状态下、某引擎世界里的完整穷举
  choiceId: string;
  stateDigest: Digest;
  engineId: EngineId;
  players: { playerId: string; kind: 'person' | 'chance' | 'environment'; personId: PersonId | null; strategies: string[] }[];
  payoffs: { personId: PersonId; strategy: string; deltaU: number; signalIds: string[] }[];
  qre: { personId: PersonId; strategy: string; probability: number }[];
  qreIterations: number;
  profiles: { profile: string[]; probability: number; outcomeId: string }[];   // 全部策略组合
  outcomes: { outcomeId: string; probability: number; direction: number }[];
}

interface NodeSuperposition {              // 坍缩前，第 k 个阶段在某状态下的叠加
  choiceId: string;
  stateDigest: Digest;
  perEngine: { engineId: EngineId; rho: number; outcomes: { outcomeId: string; probability: number; alignment: number }[] }[];
  outcomes: { outcomeId: string; classical: number; interference: number; probability: number }[];
  normalization: number;                   // Z_k
}
```

## 8. 现实情境

```ts
interface RealityContext {
  schema: 'reality/1';
  contextId: string;
  version: number;                         // 用户每次修改 +1；旧版本保留，以便比较新旧路径
  asOf: CivilDate;
  family: {
    parents: { personId: PersonId; living: boolean | null; residenceRegion: string | null;
               occupationClass: string | null; coResident: boolean | null }[];
    siblings: { count: number | null; birthOrder: number | null };
    householdWealthBandInChildhood: 0 | 1 | 2 | 3 | 4 | null;
    events: RealityFact[];                 // 家庭重大变故
  };
  upbringing: { regionCode: string; city: string | null; urbanRural: 'urban' | 'rural' | 'mixed' | null; decades: number[] };
  facts: RealityFact[];
  completeness: Partial<Record<ChoiceType, boolean>>;   // 领域完整性声明
  current: {
    residence: { regionCode: string; city: string | null };
    workStatus: PersonState['workStatus'] | null;
    partnership: PersonState['partnership'];
    childrenCount: number | null;
    healthAttention: 'none' | 'attention' | null;
    pendingChoices: { choiceType: ChoiceType; expectedYear: number | null }[];
  };
  significantOthers: { personId: PersonId; role: RelationRole; from: number | null; to: number | null }[];
}

interface RealityFact {
  itemId: string;                          // 稳定 ID，用于归因
  choiceType: ChoiceType;
  outcome: string;                         // 与选择目录中的 outcomeId 对应
  persons: PersonId[];
  yearFrom: number; yearTo: number;        // 允许区间
  origin: 'user_entered' | 'ai_draft_confirmed';
}

interface RealityConflict {
  kind: 'fact_against_engine' | 'engine_without_fact' | 'fact_without_engine';
  choiceId: string | null;
  realityItemId: string | null;
  engineId: EngineId | null;
  ruleIds: string[];
  likelihoodRatio: number | null;
  explanation: string;                     // 由模板生成，不由 AI 生成
}
```

## 9. 唯一路径与输出

```ts
interface UniquePath {
  schema: 'unique-path/1';
  selectionMethod: 'map' | 'seeded_sample';        // 10 文档 D4
  seed: { material: 'sha256(canonical self BirthInput)'; value: Digest; } | null;
  address: WorldAddress;
  segments: { past: PathNode[]; projected: PathNode[] };
  boundary: { horizonYear: number; label: '推演边界，不是寿命估计' };
  probability: { posterior: number; prior: number; realityCompatibleMass: number };
  mapReference: { address: WorldAddress; posterior: number } | null;   // 抽样方案下附带最大概率路径
  neighbors: RejectedWorld[];                      // 被排除的邻近世界
  conflicts: RealityConflict[];
  engineFit: { engineId: EngineId; log2LikelihoodRatio: number; perNode: { choiceId: string; ratio: number }[] }[];
  coverage: { constrainedPastNodes: number; pastNodes: number; posteriorEntropyBits: number };
  stability: StabilityReport;
  bounds: MaterializationBounds;
  algorithmVersion: AlgorithmVersion;
  inputDigests: { persons: Record<PersonId, Digest>; reality: Digest | null; request: Digest };
}

interface PathNode {
  choiceId: string;
  year: YearSlot;
  outcomeId: string;
  segment: 'fact' | 'fact_partial' | 'inferred' | 'projected';
  probability: number;                     // 该节点所选结果的条件概率（测量后）
  bestAlternative: { outcomeId: string; probability: number };
  stateAfter: WorldState;
  trace: TraceChain;
  flags: ('low_probability' | 'no_engine_direction' | 'reality_only' | 'activated_by_fact')[];
}

interface TraceChain {                     // 每个节点必须能完整回溯
  address: WorldAddress;
  superposition: NodeSuperposition;
  games: StageGame[];                      // 每个引擎一个
  choice: MajorChoice;                     // 含 sources → candidate → branchPoint → signal → ruleId
  realityItems: string[];                  // 起作用的现实条目
  rules: { ruleId: string; verification: Verification }[];
}

interface RejectedWorld {
  address: WorldAddress;
  posterior: number;
  divergesAt: string;                      // 第一个不同的 choiceId
  reason: 'lower_probability' | 'excluded_by_fact' | 'excluded_by_current_state';
  realityItemId: string | null;
}

interface StabilityReport {
  kIncrease: { from: number; to: number; samePrefixLength: number; changedNodes: string[] };
  parameterSensitivity: { parameter: string; stableRange: [number, number] }[];
  engineAblation: { engineId: EngineId; changedNodes: string[] }[];
  bruteForceCheck: 'passed' | 'skipped_too_large';
}

interface PathDiff {
  schema: 'path-diff/1';
  fromRealityVersion: number; toRealityVersion: number;
  changes: { choiceId: string; before: PathNode | null; after: PathNode | null;
             causes: { realityItemIds: string[]; mechanism: string[] } }[];
}
```

## 10. 管线结果

```ts
type PipelineResult =
  | { ok: true; stage: 'complete' | 'awaiting_reality'; path: UniquePath | null;
      deliveries: EngineDelivery[]; primaryWorlds: PrimaryWorld[]; extraction: ExtractionResult;
      warnings: PipelineWarning[]; algorithmVersion: AlgorithmVersion }
  | { ok: false; stage: 'input' | 'engines' | 'worlds' | 'choices' | 'multiverse' | 'reality' | 'collapse';
      error: { code: string; message: string; detail: unknown }; partial: Partial<...>; algorithmVersion: AlgorithmVersion };
```

管线永不抛异常；任何异常在模块边界被捕获并转为 `ok: false`，带出错阶段和已完成部分。单个引擎失败不使整体失败：该引擎记为失败、不进入世界生成，结果中如实列出。
