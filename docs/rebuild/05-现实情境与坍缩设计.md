# 05 · 现实情境与坍缩设计

> 接 `04-世界生成设计.md`。来源标签同前：【典籍】【数学】【自定】。
> **关于「量子」一词的技术声明**：本文的「态、振幅、干涉、测量、坍缩」是借用量子力学的数学形式（复向量、内积、投影）在普通计算机上做的经典计算。没有使用量子硬件，也不主张存在任何物理量子效应。产品文案保留「量子坍缩」作为正式名称，技术文档按本声明描述。

## 0. 结论先行

1. **现实情境是用户对自己真实世界的结构化描述**，字段与世界模型一一对应。每个字段都写明它在坍缩中起什么作用；起不了作用的字段不收集。
2. **多元分析有四项计算**：排除（与事实矛盾的世界概率置零）、定位（确定「现在」在世界树的哪个状态）、吻合度（每个引擎对已发生事实的预测得分）、冲突报告（引擎与现实不一致之处，显式输出）。
3. **态的定义**：每个选择节点上，每个引擎贡献一个振幅；振幅的模来自该引擎世界里的博弈概率，相位来自该引擎对结果的判断方向，**判断越明确，相干成分越大**。同一节点上不同引擎的振幅叠加并干涉；不同历史之间正交（事件一旦发生就被记录，相当于退相干）。由此推出一个可解释的性质：**引擎一致 → 分布变尖（更确定）；引擎冲突 → 分布变平（更不确定）**。
4. **测量**：现实情境是一个作用在历史空间上的（可带权的）投影算子。测量后的态归一化，就得到「与现实相容的世界」上的概率分布。
5. **求解**：因为不同历史之间正交、每个节点的概率只依赖当时的状态，整个二级世界是一条有限状态的马尔可夫链。最大概率路径、精确归一化常数和每个节点的边缘概率都可以用动态规划精确求出，不需要物化全部世界。
6. **最后一步怎么选出唯一路径，需要你拍板**（10 文档 D4）。我在推导中发现一个你需要知道的问题：**「取概率最大的路径」在长序列上会系统性地偏向「什么都不发生」的人生**，因为每个变动节点单独看往往都不到 50%。我倾向于「由出生信息派生种子、在每个节点按概率抽样」（并始终同时展示最大概率路径和每个节点的概率），但这是产品取向问题，由你决定。

### 1.2 采集方式

**分步引导问卷为主，自由文本为辅。**

- 问卷按区块分页，每页 3–5 个问题。每个问题旁边显示「这一项会影响什么」，例如「你的迁居经历会用来排除与事实不符的世界」。
- 所有事实条目都是「年份 + 类型」的结构化选择，年份可以填区间（例如「2016–2017 年间」）。
- **自由文本转结构化（可选，待你确认，见 10 文档 D1）**：用户可以写一段话，由 AI 抽取成结构化条目。这一步是非确定性的，所以规则是：AI 只生成「草稿条目」，每一条都必须经用户逐条确认或修改后，才写入现实情境；之后的全部计算只读已确认的条目。确认后的条目记录 `origin: 'ai_draft_confirmed'`，原始自由文本默认不保存（用户可选择保存），以减少敏感数据。
- 录入他人信息前显示一句提示（宪法要求）：「你将录入另一个人的信息。这些信息只用于生成你自己的世界，只有你能看到，删除你的账号时会一并删除。请只录入你认为对方不会反对的内容。」

### 1.3 只填了一部分时

系统照常坍缩，同时如实告知把握程度下降。第一版用两个可解释的量，不用笼统的「置信度」：

- **约束覆盖率**：已物化的过去节点中，有事实约束的比例。例如 4 个过去节点中有 3 个被事实确定，覆盖率 75%。
- **路径的后验熵**：坍缩后过去段的不确定性，单位为比特（0 表示过去完全被事实确定）。

界面上这两个量转成文字：「你提供的事实确定了过去 4 个关口中的 3 个；剩下 1 个是推断的。」（07 文档）

## 2. 多元分析

记二级世界中一条完整历史为 h = (o₁, o₂, …, o_K)，o_k 为第 k 个节点的结果（含时间槽）；记现实情境中的事实集合为 F。

### 2.1 排除（与已发生事实矛盾的世界）

对每条事实 f ∈ F 和每条历史 h，定义匹配核 κ_f(h) ∈ [0, 1]【自定】：

```
若 f 的类型与 h 中某节点 k 的选择类型相同、结果相同、人物相同：
    κ_f(h) = κ(Δt)，Δt = f 的年份与 o_k 时间槽的距离（年）
    κ(0) = 1，κ(1) = 0.5，κ(Δt ≥ 2) = 0
若 h 中没有任何节点能解释 f：κ_f(h) = 0
若 f 是「领域 d 已声明完整」，而 h 在 asOf 之前的 d 领域中有 f 之外的变动结果：κ_f(h) = 0
```

测量权重 m(h) = Π_f κ_f(h)。m(h) = 0 的历史被排除。

**事实激活候选池**：如果某条事实在已物化的节点中找不到解释，先在候选池（未进入前 K 的候选选择）中寻找类型、人物相同且时间在 τ 内的候选。找到就把它**激活**，加入物化节点（物化边界的输出中记录 `activatedByFact`）。找不到时，为这条事实建立一个**现实强制节点**：结果被事实固定，引擎振幅按「无信号」计算，打标 `reality_only`。它表示现实中发生了一件引擎完全没有指向的事。

### 2.2 定位（当前状态在世界树的什么位置）

`asOf` 那一年的当前状态 S_now 也是一条约束：历史 h 在 asOf 时的状态 s_h(asOf) 必须与 S_now 中用户填写了的变量一致，否则 m(h) = 0。没填的变量不约束。「正面临的抉择」把对应节点的机会参与者测量为「出现」（概率为 1）。定位之后，asOf 之前的节点构成「已发生段」，之后的构成「推演段」。

### 2.3 吻合度（每个引擎与现实的吻合程度）

对每个引擎 e，计算它对已发生事实的预测概率与「无信息基准」的比值：

```
LR_e = Π_{过去节点 k 有事实约束} P_e,k(o_k^事实) / P_0,k(o_k^事实)
P_0,k：该节点在所有信号为 0、P(arise) = b₀ 时的概率（同一套博弈规则）
```

LR_e > 1 表示该引擎对这个人的过去「预测得比瞎猜好」，< 1 表示更差。输出每个引擎、每个节点的比值，以及 log₂LR_e 的总和。它**只用于展示和反馈积累，不回写到权重**；在有足够多用户的样本之前，一个人的几个事实不足以校准引擎（11 文档）。

### 2.4 现实与命理冲突的呈现

冲突不抹平，作为 `RealityConflict` 显式输出，三种类型：

| 类型 | 判定 | 例子 |
|---|---|---|
| `fact_against_engine` | 事实对应的结果，在某引擎世界里的概率低于基准（LR_e,k < 1） | 紫微对 2016 年婚姻给出不利倾向，但用户 2016 年结婚 |
| `engine_without_fact` | 某领域已声明完整，而某个物化或候选池中的节点在该领域指向变动、权重 ≥ 候选池中位数，但事实中没有对应变动 | 八字 2019 年子女关键节点，用户声明「无子女，已列全」 |
| `fact_without_engine` | 事实只能由现实强制节点解释 | 用户 2021 年创业，没有任何引擎在附近时段指向这类选择 |

## 3. 态与振幅

### 3.1 节点上的振幅

在阶段 k、状态 s 下，引擎 e 对结果 o 的振幅定义为一个向量（在由一个「相干方向」|c⟩ 和每个引擎各自的「非相干方向」|i_e⟩ 张成的空间中，这些方向两两正交）：

```
|ψ_e,k(o)⟩ = √(ρ_e · P_e,k(o | s)) · [ sgn(a_e(o)) · √|a_e(o)| · |c⟩  +  √(1 − |a_e(o)|) · |i_e⟩ ]
```

- **模**：P_e,k(o | s) 是引擎 e 的世界里，04 文档 §4 的博弈给出的结果概率。ρ_e 是引擎权重：ρ_e = statusFactor(e) / Σ statusFactor（04 文档 §3.2）【自定】。
- **判断方向 a_e(o) ∈ [−1, 1]**：引擎 e 对「结果 o 对本人是好是坏」的判断，取 v_e(o) = s_{本人,e}(k) × d(o) 再减去各结果的均值并截断到 [−1, 1]。d(o) 是选择目录中结果的方向（「结婚」+1、「未婚」0；「迁且顺利」+1、「迁但受挫」与「未迁」0 等）【自定】。
- **相位**：sgn(a) 为正时相位为 0，为负时相位为 π。引擎的判断越明确（|a| 越大），振幅中相干的部分越大；没有判断（a = 0）时，振幅完全落在该引擎自己的非相干方向上，不与任何引擎干涉。

**为什么相位只取 0 和 π**：任意角度的相位需要一个有规则依据的量来决定它。命理规则给得出「吉 / 凶 / 中性」，给不出「37° 的吉」。用一个看起来精细的角度，就是编造。这一点是对你「各引擎的一致与冲突体现为相位」设想的具体化，也是它的边界。

**为什么用「部分相干」而不是纯相位**：我最初的方案把「中性」编码为相位 π/2，推演后发现两个都中性的引擎会互相增强，结果系统性地偏向「维持现状」。改为「中性 = 不相干」后，这个偏差消失。

### 3.2 叠加、干涉与归一化

节点 k 上结果 o 的总振幅 |Ψ_k(o)⟩ = Σ_e |ψ_e,k(o)⟩，未归一化概率为其模方：

```
‖Ψ_k(o)‖² = Σ_e ρ_e P_e(o)                                            （经典混合项）
          + 2 Σ_{e<f} √(ρ_e ρ_f P_e(o) P_f(o)) · √(|a_e(o)| |a_f(o)|) · sgn(a_e(o)) sgn(a_f(o))   （干涉项）
P_k(o | s) = ‖Ψ_k(o)‖² / Z_k(s)，Z_k(s) = Σ_o ‖Ψ_k(o)‖²
```

【数学】这是两个带内积的向量之和的模方展开，与量子力学中振幅叠加的计算形式相同。

**性质（可解释性的来源）**：在二元结果的节点上，a_e(结果1) = −a_e(结果2)，所以任意两个引擎在两个结果上的符号乘积 sgn·sgn 相同。因此：

- 两个引擎**判断一致**时，干涉项在两个结果上都为正，且正比于 √(P_e P_f)。本来就更可能的结果得到更多的增强 → **分布变尖，更确定**。
- 两个引擎**判断相反**时，干涉项在两个结果上都为负，本来就更可能的结果被削减得更多 → **分布变平，更不确定**。
- 只有一个引擎有判断，或所有引擎都中性时，没有干涉项，结果就是按 ρ 加权的经典混合。
- 只有一个引擎时，结果严格等于该引擎世界里的博弈概率（这是一条必测性质）。

所以「引擎的一致与冲突」不改变方向，方向由各引擎自己的概率决定；一致与冲突改变的是**确定程度**。这是一个可以向用户解释的结论。

### 3.3 历史之间为什么不干涉

一条历史的振幅定义为各节点归一化振幅的张量积，历史的概率为各节点概率之积：

```
P(h) = Π_k P_k(o_k | s_{k−1}(h))
```

不同的历史在至少一个节点上结果不同，而结果一旦发生就写入了世界状态（被「记录」），所以不同历史对应的状态正交，彼此不干涉。这对应量子力学中的退相干：被环境记录下来的不同结果之间失去相干性【数学：这是建模选择，不是物理推论】。

这样定义有两个好处：① 历史概率自然归一（Σ_h P(h) = 1），不需要对指数级的历史求和来算归一化常数；② 每个节点的干涉都是局部的，可以向用户逐个节点解释。代价是：不同节点之间不存在干涉，「整条人生路径与另一条路径相干」这种效应在本模型中不存在。

## 4. 测量、坍缩与求解

### 4.1 测量

现实情境定义一个对角的测量算子 M，M|h⟩ = √m(h)|h⟩，m(h) = Π_f κ_f(h)（§2.1–2.2）。测量后的分布【数学：Lüders 规则的对角情形】：

```
P(h | 现实) = m(h) P(h) / Σ_h' m(h') P(h')
```

分母 Σ_h m(h)P(h) 是「先验中与现实相容的世界的总概率」，作为 `realityCompatibleMass` 输出。它很小，说明现实与引擎的先验很不一致（同时看 §2.4 的冲突报告）。

### 4.2 无穷空间上的求解

世界状态是有限的离散变量组合，每个节点的结果概率只依赖进入该节点时的状态，测量权重也按节点分解（每条事实只约束一个节点或 asOf 时的状态）。所以「历史 + 测量权重」是一条有限状态的非齐次马尔可夫链【数学】，可以做到：

| 目标 | 算法 | 复杂度 | 是否精确 |
|---|---|---|---|
| 归一化常数、每个节点的边缘概率 | 前向—后向算法 | O(K × \|S\| × \|O\| × \|Σ\|) | 精确 |
| 最大概率路径 | Viterbi（max-product 动态规划） | 同上 | 精确 |
| 按概率抽样 | 前向滤波 + 逐节点条件抽样 | 同上 | 精确 |

其中 K 为节点数，|S| 为可达状态数，|O| 为每节点结果数（2–4），|Σ| 为每节点策略组合数（≤ 48，用于求 QRE）。状态只记录选择会改写的变量，第一版每个节点结束时的可达状态数是数十到数百量级（按 04 文档 §1.2 的变量表估计，未实测）。

**最优性的含义**：在物化边界（K、r、H、目录版本、参数）给定的有限空间内，Viterbi 给出的是**全局**最大概率路径，精确，不是近似。但它**不是**无穷空间（K → ∞，r → ∞）上的最优：未物化的选择被视为不存在，更细的时间精度被视为均匀。§5 用稳定性检验来衡量这个差距。

若将来状态空间爆炸（例如人物很多、变量很多），退路是束搜索加上界剪枝：每个节点保留前 B 个状态，并对被剪掉部分的概率总和输出上界，这时路径只是「束内最优」，输出里标 `approximate: true` 和误差上界。

**时间精度的逐级坍缩**：先在年精度上选出路径，再在每个已选的年内，以月精度在条件分布中选出月份，依此类推。这样细化**永远不会改变**已经选定的粗粒度路径（嵌套一致）。代价是：它不等于「直接在月精度上求全局最优」。我选择嵌套一致，因为「唯一路径」在精度提高时还在变，对用户来说比「不是月精度上的严格最优」更难接受。

### 4.3 最后一步：取最大概率路径，还是抽样

| | A. 取最大概率路径（Viterbi） | B. 出生信息派生种子，逐节点抽样 |
|---|---|---|
| 确定性 | 是 | 是：种子 = SHA-256(规范化的本人出生输入)；节点 k 的均匀数 u_k = 取 SHA-256(种子 ‖ 节点稳定键) 的前 53 位除以 2⁵³。节点稳定键 = 选择类型 + 窗口 + 人物集合，不依赖节点序号 |
| 可解释性 | 最强：「这条路径概率最高，第二名是…，差多少」 | 中等：「在这个关口，结果按概率分布落在这里；这个结果的概率是 x%，最可能的结果是 y」 |
| 与量子测量的对应 | 弱：测量结果不是取最大值 | 强：玻恩规则就是按概率抽样 |
| 稳定性 | 只在概率近乎并列时翻转 | 某节点概率变化时，只有 u_k 落在变化区间内才翻转；u_k 与节点序号无关，其他节点不受牵连 |
| **系统性偏差** | **偏向「什么都不发生」**：每个变动节点的概率往往低于 50%，取最大值会让未来段几乎全部是「维持现状」，K 越大越明显。高维空间里，概率最大的单点本身就是不典型的 | 无此偏差：抽到的是一条「典型」路径 |
| 风险 | 输出一条平淡、不真实的人生 | 可能抽中一个低概率的结果并把它作为「命运」呈现 |

**我的建议**：B，配合三条约束：① 界面上每个节点同时显示所选结果的概率和概率最大的结果；② 所选结果概率低于 10% 的节点打标「低概率关口」；③ 输出中始终附带 A 的路径作为对照。这是 10 文档 D4，待你拍板。在本文的例子里，A 与 B 恰好选出同一条路径。

### 4.4 唯一路径的两段

- **已发生段**（asOf 之前）：每个节点标三种来源之一：`fact`（事实直接确定）、`fact_partial`（事实确定了结果类别，例如「迁居了」，但没确定子结果，例如顺利或受挫）、`inferred`（没有事实，按后验选出）。
- **推演段**（asOf 之后）：全部是推演，标 `projected`。
- 终点是「推演边界」H，不是寿命估计，界面上逐字显示「推演边界：2032 年。这是本次分析覆盖的范围，不是寿命估计」。

## 5. 稳定性检验

| 检验 | 做法 | 判定 |
|---|---|---|
| 选择数扩大 | K → K + 4，比较原 K 个节点上的选择结果 | 结果相同的节点比例；第一个不同的节点位置 |
| 时间精度提高 | r：年 → 月 | 由于逐级坍缩，年精度路径不变（必测性质）；另外输出「直接在月精度求解」的路径作为对照 |
| 参数扰动 | λ、b₀、ι、κ 各自 ±20%，逐个扰动 | 路径不变的参数区间 |
| 引擎增删 | 逐个去掉一个引擎重算 | 路径变化归因到引擎 |
| 小规模暴力对照 | K ≤ 8 时完全枚举全部历史 | 与动态规划结果逐位一致 |

稳定性结果作为 `StabilityReport` 写入输出，界面上转成文字：「这条路径在选择数增加、参数变化 ±20% 时保持不变」或「这条路径对参数 b₀ 敏感」。

## 6. 例子（续 04 文档 §5）

### 6.1 坍缩前：各节点的叠加

**N1（2016 结婚）**：八字 P(结婚) = 0.0928，判断方向 a = 0（八字第一版无极性）；紫微 P = 0.0446，a_紫微(结婚) = −0.5（A 的 relationship 信号为 −1，中心化后为 −0.5）。只有紫微有方向 → 无干涉，经典混合：ρ_八字 = 0.6 / 0.9 = 2/3，ρ_紫微 = 1/3：

```
P(结婚) = 2/3 × 0.0928 + 1/3 × 0.0446 = 0.0767
```

**干涉演示（假设性）**：设第 6 阶段加入的引擎 X（例如西方占星，ρ 与八字相同为 2/3）在 2016 年对 A 的婚恋给出 favorable（s_A = +1），其博弈得到 P_X(结婚) = 0.1050。X 与紫微判断相反：

```
结婚：相干分量 = √(2/3×0.105×0.5) − √(1/3×0.0446×0.5) = 0.1871 − 0.0862 = 0.1009；相干² = 0.0102
      非相干 = 2/3×0.105×0.5 + 1/3×0.0446×0.5 = 0.0424；未归一化 = 0.0526
未婚：相干分量 = −√(2/3×0.895×0.5) + √(1/3×0.9554×0.5) = −0.5462 + 0.3990 = −0.1472；相干² = 0.0217
      非相干 = 0.4576；未归一化 = 0.4792
Z = 0.5318；P(结婚) = 0.0526 / 0.5318 = 0.0989
```

经典混合为 2/3 × 0.105 + 1/3 × 0.0446 = 0.0849。冲突使分布变平：P(结婚) 从 0.0849 升到 0.0989，「未婚」相应下降。若两个引擎判断一致，同样的计算得到 P(结婚) = 0.0798，分布变尖，偏向本来更可能的「未婚」。

**N2（2016 迁居）**：两引擎在 A 本人的迁居相关领域都无方向 → 经典混合：迁且顺利 0.0531，迁但受挫 0.0265，未迁 0.9204。

**N3（2028 解除伴侣关系）**：无方向 → P(解除) = 2/3 × 0.3263 + 1/3 × 0.2828 = 0.3118。

**N4（2028 迁居）**：紫微对 A 有 career favorable → a_紫微 = (迁且顺利 +0.667，受挫 −0.333，未迁 −0.333)；八字无方向 → 仍无干涉。条件概率见 §6.3 表格。

### 6.2 现实情境 R1

```
asOf: 2026-06-01
facts:
  - partnership: formed, 2016, A+B                    （事实 f1）
  - residence: moved, 2017, A+B, 北京 → 杭州          （事实 f2）
  - children: 无，完整性声明：是                       （事实 f3）
  - residence 完整性声明：是（2014–2026 只有这一次迁居）
current:
  residence: 杭州；partnership: married；father F: 住北京（不同城）
pending choices: 无
```

**多元分析**：

- **排除**：f1 要求 N1 = 结婚（κ = 1）。f2 的类型、人物与 N2 一致，结果为「迁」，年份 2017 与窗口 2016 相差 1 年 → κ = 0.5；N2 = 未迁的历史无法解释 f2 → 排除。f3 与已物化节点无关（子女候选在候选池中，未物化）。
- **定位**：asOf 2026 时 A 在杭州、已婚 → 要求 N2 ∈ {迁且顺利，迁但受挫}，N1 = 结婚。推演段为 N3、N4；N4 中 F 不与 A 同城 → F 不是参与者。
- **先验中与现实相容的质量**：P(结婚) × P(迁) = 0.0767 × 0.0796 = 0.0061；乘上 κ = 0.5 后为 0.0031。这个数很小，说明在第一版引擎下，这段过去在先验中并不突出。这符合预期：八字没有方向，紫微对这段婚姻是不利倾向。
- **冲突报告**：
  - `fact_against_engine`：N1，紫微 P_紫微(结婚) = 0.0446，基准 P₀ = 0.0804（所有信号为 0、P(arise) = 0.5 时的同一博弈），LR = 0.55。即「紫微对 A 2016 年的婚恋给出不利倾向（廉贞化忌入夫妻宫，规则 `ziwei.signal.liunian-ji-palace`，unverified），但 A 于 2016 年结婚」。八字 LR = 0.0928 / 0.0804 = 1.15。
  - `engine_without_fact`：候选池中 A·八字 children 2019（权重 0.08，`bazi.keynode.clash-hour-branch`），用户声明「无子女，已列全」。
  - 时间偏差提示：迁居发生在 2017 年，引擎窗口为 2016 年，相差 1 年。

### 6.3 R1 下的坍缩

**已发生段**：N1 = 结婚（`fact`）。N2：后验中「迁且顺利」:「迁但受挫」= 0.0531 : 0.0265 = 0.667 : 0.333（两者 κ 相同），事实只确定了「迁了」→ 标 `fact_partial`。

**推演段**（N3 → N4，N4 依赖 N3 的结果）：

| N3 | N4 | 计算 | 联合概率 |
|---|---|---|---|
| 继续 0.6882 | 未迁 0.9055 | 0.6882 × 0.9055 | **0.6232** |
| 解除 0.3118 | 未迁 0.7788 | | 0.2428 |
| 解除 | 迁且顺利 0.1475 | | 0.0460 |
| 继续 | 迁且顺利 0.0630 | | 0.0434 |
| 解除 | 迁但受挫 0.0737 | | 0.0230 |
| 继续 | 迁但受挫 0.0315 | | 0.0217 |

（N4 的条件概率：继续婚姻时 B 是参与者，需要 B 同意，迁居概率较低；解除后 A 单独决定，紫微的 career favorable 起更大作用。）

- **方案 A（最大概率路径）**：结婚(2016) → 迁且顺利(2016–17) → 继续婚姻(2028) → 未迁(2028)。后验概率 = 0.667 × 0.6232 = **0.4157**；先验概率（测量前）= 0.0767 × 0.0531 × 0.6882 × 0.9055 = 2.54 × 10⁻³。
- **方案 B（抽样）**：种子 = SHA-256(A 的规范化出生输入) = `1d2a0413…89b7c`。u(N2) = 0.6293，u(N3) = 0.5969，u(N4) = 0.5851。各节点按「维持现状在前，其余按目录顺序」排列结果并取累积区间：N2 中「未迁」后验为 0，「迁且顺利」占 [0, 0.667) → 抽中迁且顺利；N3「继续」占 [0, 0.6882) → 继续；N4「未迁」占 [0, 0.9055) → 未迁。与方案 A 相同。
- **被排除的邻近世界**（按后验概率）：① 2028 年解除伴侣关系、未迁（0.667 × 0.2428 = 0.162）；落选原因：N3 处「继续」的概率 0.688 高于「解除」0.312，且这一差距完全来自【自定】参数（规则信号为中性）。② 2016–17 年迁但受挫（过去段的另一子结果，0.333 × 0.6232 = 0.208）；落选原因：环境先验 2:1，没有事实区分。
- **每个节点的回溯链**（以 N4 为例）：N4「2028 年未迁」← 二级世界地址 `v1/<root>/N1=formed@Y2016/N2=moved_ok@Y2016/N3=continue@Y2028/N4=stay@Y2028` ← 策略：A「留」（紫微世界 P = 0.41，八字世界 P = 0.60）、B「反对」…（列出全部策略组合及其概率）← 选择 residence-2028 由 A·八字 `bazi.keynode.clash-day-branch`（2028 戊申冲日支寅，w = 0.056）与 B·八字同规则（w = 0.056）联合提取，联合权重 0.1089 ← 规则来源：《三命通会》论六冲（卷章待查，cited_unverified）+ 应期解读（unverified）。

### 6.4 改动一项现实信息：R2

R2 只改动一项：把事实 f2「2017 年迁居杭州」改为「**2014–2026 年没有迁居，一直住在北京**」（迁居完整性声明不变），当前所在地相应改为北京。

**重新坍缩**：

- N2：「迁」的两个子结果都无法与「没有迁居」相容 → 排除；N2 = 未迁（`fact`）。先验相容质量 = 0.0767 × 0.9204 = 0.0706。
- 状态：A 与 F 在 2028 年同城 → N4 中 F 成为参与者，A「迁」的收益多一项 −0.5 × P(F 反对)。
- N4 的条件概率变为：继续婚姻时未迁 0.9132（R1 为 0.9055）；解除后未迁 0.8288（R1 为 0.7788）。

**新路径**（方案 A 与 B 结果相同）：结婚(2016) → 未迁(2016) → 继续婚姻(2028) → 未迁(2028)，后验 0.6285。

**差异呈现**（`PathDiff`）：

| 节点 | R1 | R2 | 原因（回溯到现实条目） |
|---|---|---|---|
| N2 2016 迁居 | 迁且顺利（`fact_partial`） | 未迁（`fact`） | 现实条目 `facts.residence[2017]` 被删除，`facts.residence.complete = true` |
| N4 2028 迁居 | 未迁，P = 0.9055 | 未迁，P = 0.9132 | 选中结果不变，概率变化。因果链：`facts.residence[2017]` → N2 = 未迁 → 2028 年状态 `coLocatedWith` 含 F → F 成为 N4 参与者 → A「迁」的收益在八字世界中减 0.25、在紫微世界中减 0.06 |
| N3 2028 | 继续，0.6882 | 继续，0.6882 | 无变化 |

**归因方法**（用于多项现实信息同时改变的情况）：对每一项变化的现实条目，单独把它恢复成旧值重算；能使某个节点变回旧结果的条目，就是该节点变化的原因。条目的处理顺序按条目 ID 排序，结果确定。若一个节点的变化需要多项条目共同作用，就报告这个最小组合。

### 6.5 稳定性（本例）

- K = 4 → 5：第 5 名是 A·八字 children 2019。R1 中 f3「无子女、已列全」把它测量为「未生育」。子女数在第一版目录里不影响迁居和婚姻节点的收益，所以原 4 个节点的选择不变 → 稳定。
- λ、ι、b₀ 各自 ±20%（逐个扰动）：N3 的 P(解除) 在 0.261（b₀ = 0.4）到 0.363（b₀ = 0.6）之间，「继续」始终高于 0.63；三者同时朝不利方向扰动（λ = 1.6、ι = 0.4、b₀ = 0.6）时 P(解除) = 0.415，仍未过半，N3 的选中结果不变。N4 在扰动下的情况本例没有逐一手算，留给实现后的 `StabilityReport`。注意这只说明路径对参数扰动稳定，不说明参数本身是对的。
- 以上为本例的手工检验；正式实现中由 `StabilityReport` 自动计算并输出。
